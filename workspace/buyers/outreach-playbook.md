## 一、核心结论（2026 共识）

| 原则 | 数据 / 依据 |
|------|-------------|
| **信号 > 名单** | 基于买家真实动态（扩店、上新、找供应商）的外联回复率 15–25%，泛模板仅 2–3% |
| **短** | 首封 **50–125 词**（英文）；>200 词回复率显著下降；elite <80 词 |
| **第一封不报价、不推销** | 不报价的首封回复率是直接推销的 **2 倍** |
| **跟进决定胜负** | 首封只拿 58% 回复，42% 来自跟进；80% 成交在第 3–5 封后 |
| **质量 > 数量** | 每天精选少量深度个性化，远胜群发 |
| **一个 CTA** | 一封信只问一个低门槛 yes/no 问题 |
| **少放链接/附件** | 首封默认少链接；**唯一允许主动附的外链** = 厂站 `https://www.yuefubbq.com`（仅背书，见 §三.8）；附件按 `cofounder.md`（hero + one-pager）；目录/证书等回复后再发 |

## 二、外联五段结构（PAR / Signal-Bridge-Value）

```text
1. Subject   3–7 词，含「公司名/具体价值点」，小写，无 Free/Discount/全大写
2. Opener    1 句，证明你看过对方（具体、可验证的观察）——不是「I noticed your company…」
3. Value     1–2 句，用买家语言说你解决什么 + 1 个证据点（数据/相似案例）
4. Ask       1 句，低门槛 yes/no 问题
5. Signature 1 行，名字 + 角色，无其他
```

- 总长 75–125 词，阅读 8–15 秒。
- 每次只改一个变量做 A/B（先测 subject，再 opener，再 CTA），每版 ≥100 封再下结论。

## 三、Kamado / 澳洲 场景落地要点

> 结合我们实际（无 YUEFU 锁价、父亲朋友工厂、署名 **Kit Lee**；W3 规则见 `product.md` / `cofounder.md`）：

1. **Opener 用具体信号**（写进 pipeline 的 Why + Competitor signal）：
   - 「你们已在卖 Kamado Joe / Primo，但没有自有/入门价位陶瓷炭烤线」
   - 「官网有 trade / wholesale 页，正在招 stockist」
2. **Value（W3）：** 可写 **indicative market FOB**（21" ~USD $255–316，*not locked*）+ 可选零售锚点；**禁止**写成厂锁价。规则见 `company/product.md`。
3. **CTA**：`Reply YES …` / 低门槛 yes-no；可拒可应。
4. **首封只附 1 张小产品图**（`workspace/buyers/assets/email-hero-kamado.jpg`），不带目录 PDF；YES 后再发 one-pager。
5. **署名**：Kit Lee · Export — YUEFU BBQ, Foshan, China · claireleebalance@gmail.com · WhatsApp: +86 137 9461 3243（邮箱 SSOT → `company/cofounder.md`；署名被动展示；正文不另加 WA CTA）。
6. **发信拓扑**：日配额 **15**/工作日；Co-founder 说 **`今天发`** 本机实发；云端 Sales 不发 Gmail；英 Contacted≥300 停英新冷邮（2026-10-09 由 100 改为 300）。
7. **一次发齐，禁止「马上补」拆信（2026-09-23 Co-founder）：** 授权「回 #N」时，**正文 + 约定附件必须同一封发出**。附件挂不上（MCP/体积/工具限制）→ **整封先不发**，等用户手工附齐或工具就绪后再发。**禁止**先发正文再发「PDF 马上补」之类占位信；同线程短时间连发多封不合适。
8. **厂站仅作可信背书（2026-09-23 Co-founder）：** `https://www.yuefubbq.com` = YUEFU 工厂独立站。**用途：** 证明厂存在 / OEM·产线·产品页可点开看。**邮件（冷邮 / 跟进 / 回盘）均可附该链接**，用一句带过即可，例如 *Factory site for reference: https://www.yuefubbq.com*。**不是我方买家站、不是第二 CTA：** 站上联系人是 Lynn Ling / Sarah（`sales@` / `lynnling@`），**没有 Kit Lee**；**禁止**写「请去官网填表 / Contact us / 打站上电话」；商务口仍只回 Kit（邮件 / WhatsApp）。Phase 0「不做面向买家的网站」= **不自建 Kit 落地页**；链厂站背书不冲突。

## 三点五、热线索正式回盘 / 报价纪律（2026-09-23 · 外贸失败案例复盘）

> 触发：`#369` Atom 回盘过长 + 网上外贸失败案例（碎报价、逼报量、刚读就催、自曝新人）。**冷邮仍按第一节短信**；本节只管 **Replied / 询盘回信 / WhatsApp 报价**。

### 客户真正要的

1. **价格**（已查好的数或明确区间；FOB 港口写清）
2. **交期**（生产 + 到目的国的路径；按量分档）
3. 其余规格/证书/独家 → **短答或「详见附件」**，不抢主位

### 必须做到

| 规则 | 做法 |
|------|------|
| **一条报完** | 价格 + 交期档位 + 一个下一步，尽量写进**同一条消息/同一封邮件**；善用空行分段。中间最多一句「稍等，X 点前给全套数」——**禁止**「请稍等」后再拆成 3–4 条连发报价 |
| **数字先备好** | **禁止**「I will check / 我去查下价格 / 跟货代确认后再说」作为主答复。查完再开口；运费未知时给**区间或分档**，不要空头「48 小时内回来」除非同条已给可选项 |
| **交期用选择题** | **禁止**先甩一个笼统天数，再逼「告诉我数量才能给准确交期」。应自备档位，例如：样品 1–2 台 → 上釉 7–10 天 + 快递约 X–Y 天；不足一柜试单 → 生产约 A 周（客户货代）；1×40HQ → 约 1 个月生产 + 海运。让客户 **选 A/B/C**，不要让他做「填空年采购量」 |
| **一个 CTA** | 回盘结尾只留**一个**低门槛选择（如：`21" 黑样品 / 21" 灰样品 / 先只要报价不动样`）。**禁止**同封连问：尺寸+颜色+邮编+年量+货代+试单量 |
| **问什么答什么** | 客户没问的（工厂窑线长介绍、汇率换算、多余「为你好」）默认不写。汇率**不要**每次换算成对方本币。询盘清单很长时：正面仍是价+交期+样品路径，其余压缩 |
| **拿回主导权** | 用选项引导下一步，而不是等客户出下一道题。客户沉默时由我们用**新理由**推进，而不是连环追问 |

### 禁止（热线索）

- ❌ 「I just started / 我不太熟这材料」等自曝不专业
- ❌ 已读回执后几十分钟内「I saw you've read… any questions?」
- ❌ `hello?` / `why no reply?` / 逼问为什么不回
- ❌ 报价拆成多条气泡连发（WhatsApp 尤甚）
- ❌ 客户问样品，只答「先下样保护权益」却不报样品价与交期

### 热线索跟进时效

1. **先等**：正式报价/资料包发出后，至少 **半天–1 天**（有时差按对方工作日）再跟；刚发完不追。
2. **轻跟进（第 2 触）**：不催。示例：`Hi, just checking if you've had a chance to review the details. Let me know if you need anything from my side.`
3. **再跟必须带新理由（第 3 触+）**：证书、目录页、交期档位补全、展会/节前排产节点等；**禁止**只会「还要样品吗 / 看了吗」。
4. **时效有代价**：有希望的线索拖过关键窗口（节假日、采购季）会丢单；该跟时用新理由跟，不是冷处理到客户已选别人。

### 回盘骨架（英文热线索 · 优先用）

```text
[价格一行：型号 + FOB 港 + USD 数/区间，opening 可一句带过]

Lead time — pick one:
A) samples …
B) trial below container …
C) 1×40HQ …

Next: reply A/B/C + colour. Specs/certs in attachments / one short line.
```

反面教材（勿模仿）：`#369` 首封正式回盘过长、交期单档 + 追问年量/试单量、样品运费「给邮编 48h 内算」。

## 四、跟进节奏（4–7 触点 / 14–21 天）

| 触点 | 间隔 | 内容（每次换角度，不重复「did you see my email」） |
|------|------|----------------------------------------------------|
| 1 | Day 0 | 首封外联（见模板 Template 2） |
| 2 | Day 3–4 | 跟进：补一个新卖点（EN1860-1 证书 / OEM 定制 / 破损包装方案） |
| 3 | Day 7 | 可附 1 页产品概览（价仍按 indicative / 正式 quote 规则） |
| 4 | Day 14 | 「分手信」：是否需要归档或转介同事——常有意外回复 |

发送时间：工作日目标国当地时间 9–11am 最佳。

**热线索（已报价/已回询盘）** 的间隔与话术以 **§三点五「热线索跟进时效」** 为准：先等半天–1 天 → 轻跟进 → 再跟带新理由；不要套用冷邮 Day 3 的催促感。

## 五、找买家 & 补联系人（prospecting）方法

### 5.1 渠道优先级（Kamado/AU）

```text
Google（AU 关键词） > 竞品渠道地图（BGE/KJ/Primo 经销商） > LinkedIn（找具体人） > 行业协会/展会名单
Alibaba = 找竞品 FOB，不是找买家
```

### 5.2 补联系人「瀑布式」流程

| 步 | 方法 | 拿到什么 |
|----|------|----------|
| 1 | 公司官网 Contact / About / Our Team | 通用邮箱、老板名、电话 |
| 2 | LinkedIn 公司页 → People，按职位搜 | 决策人姓名 + 职位 |
| 3 | LinkedIn Boolean：`"owner" OR "purchasing" OR "director" [公司名]` | 采购/老板 |
| 4 | 邮箱格式推断（Hunter 式）：`first.last@domain` / `first@domain` | 个人邮箱候选 |
| 5 | 高价值目标才做：找个人邮箱/手机 | 精准触达 |

### 5.3 目标职位（BBQ 分销商/零售商）

`Owner` / `Director` / `Purchasing Manager` / `Buyer` / `Category Manager` / `Sourcing`

### 5.4 联系人就绪（入 pipeline 门槛）

→ **唯一标准**：[`pipeline.md`](pipeline.md)「联系人就绪标准」。

摘要：**不要求必须有 Email**；须有至少一种可触达方式（Email / 电话 / LinkedIn 个人 / WhatsApp / 联系表单）。无任一联系方式 → 不入 pipeline。

### 5.5 多渠道协同

Email 主渠道 → 已读不回则 LinkedIn 互动（先点赞/评论 2–3 条帖，间隔一周）→ 必要时 WhatsApp 轻触达。

**WhatsApp 轻触达（政策唯一来源 → [`company/cofounder.md`](../../company/cofounder.md)）：**

- 我方号码：`+86 137 9461 3243`（`https://wa.me/8613794613243`）
- 出站：仅公开 `wa:` / 可确认手机号，或 Co-founder 点名；触发词 **`WhatsApp 发出去`**；日量 0–3；**不**改 Contacted
- **澳试点（选项 A）：** 仅已入库澳 **A** + 公开号；禁催 Brad/Martin/Angela/Alex；不扩澳、不发澳冷邮
- Notes：`YYYY-MM-DD WA light @Name`（澳试点加 `· AU-pilot`）

## 六、指标基准（自检）

| 指标 | 合格 | 优秀 | 诊断 |
|------|------|------|------|
| 回复率 | ≥5% | ≥10% | 低 = 定位/个性化/CTA 问题 |
| 正向回复率 | 3–8% | — | ICP 匹配度 |
| 退信率 | <2% | — | 名单质量（护域名） |
| 会议/询盘转化 | 20–40% | — | 从正向回复算 |

> 注：Apple 隐私保护后**打开率不可靠**，以回复率为主。

## 七、避坑清单

- ❌ `Dear Sir/Madam` 无个性化称呼
- ❌ 首封长篇 / 堆产品规格 / 直接报价
- ❌ subject 带 Free/Discount/Buy Now/全大写/>50 字符
- ❌ 跟进只重复「did you see my last email」
- ❌ 一封信多个 CTA（回信+电话+填表+「去官网联系」）— 厂站链接若写成洽谈入口即违规；写成 *for reference* 背书则不算第二 CTA
- ❌ 首封带目录 PDF、证书或多图（**hero + one-pager 除外**，见 `cofounder.md`）
- ❌ 群发同一封（X/LinkedIn 有批量检测；邮件伤域名）
- ❌ 热线索回盘：「我去查价」/ 交期单档再逼报量 / 一条拆成多条报价 / 刚读就催 / 自曝新人（详见 §三点五）
